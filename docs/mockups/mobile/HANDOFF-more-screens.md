## 追加画面の共通パターン
- マイページの各タブ・出品・受け取り: ヘッダーの下に**サブバー**（白・高さ 52px・下に 1px の線）。左に「‹ マイページ」または「‹ 戻る」（44px）、中央に画面名 16px/700。
- 一覧の行（出品中・購入希望など）: 左に画像 56×72px、タイトル 15px/700、補足 12px、下段に価格＋状態バッジ。右端の「…」（44px）で操作メニュー（取引完了にする・削除）。
- 状態バッジの色: 申請中＝黄（#fffbeb / #92400e）、承認済み＝緑（#ecfdf5 / #065f46）、日程調整中・予約済み＝青（#eff6ff / #1d4ed8）、出品中＝紺（#eef2f5 / 紺）。
- 選択肢（教科書の状態・候補日時）は**ラジオの行**（高さ 48px、左に 20px の丸）。
- 入力フォームは「左ラベル（104px）・右入力」の行。選択式（学部・学年）は右に値と山形。
- 補足説明はグループの下に 12px の灰色の文（左右 16px）。
- 下部固定の操作（出品する・質問送信）は商品詳細の購入バーと同じ作り。`BottomTabBar` の上に置き、`[data-bottom-bar]` で本文に高さ分の余白を足す。
- モック内の `[件数]` `[日付・時間帯]` `[最新のメッセージ]` などは実データが入る場所。

## 画面ごとの要点
- **トップ**: スライドショー（01〜04）はやめ、「TETOMIの特徴」の 4 行（アイコン＋見出し＋説明）に置き換える（隠れる情報をなくすため）。ヒーローは写真＋紺のかぶせ、見出し「教科書の新しい流通を、学部内に。」。その下に検索欄と「今すぐ出品する」。新着は一覧と同じ行を 3 件＋見出し帯の右に「すべて見る」。よくある質問は開閉する行。
- **出品**: 写真 → バーコード自動入力 → 基本情報 → 状態 → 価格・受け渡し（出品価格と受け取り額の 2 行を表示）→ コメント の順にセクションを並べる。
- **受け取り・お支払い**: 教科書の行 → 受け渡し（日時・場所・出品者）→ 受け渡し用QR（説明＋「カードを登録してQRを表示」）。
- **受け取った購入希望**: 行の下に候補日時のラジオ行 → 「この日時で承認する」（主ボタン）→「別の日程を提案」「断る（赤）」の文字ボタン。
- **送った購入希望**: 行の下に「提示した候補（出品者の選択待ち）」の行 →「購入希望を取り下げる（赤）」。承認済みは「受け取り・お支払いへ ›」の行を付ける。
- **メッセージ**: 相手ごとの行（アバター 44px・名前・教科書名・最新メッセージ・時刻・未読バッジ）。「購入希望」「受け取った希望」でセクションを分ける。

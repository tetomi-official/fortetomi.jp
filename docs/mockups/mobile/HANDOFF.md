## 適用範囲
- **md（768px）未満だけ**に適用する。境目は既存の `BottomTabBar`（`md:hidden`）と同じ。
- md 以上（タブレット・PC）は今のカードのレイアウトのまま。変えない。
- `docs/mockups/mypage-responsive/` の案A（スマホ版 `Main.dc.html`）は、md 未満については本ハンドオフで置き換え。タブレット版（`TabletA.dc.html`）は有効。

## 実装のしかた
- Tailwind で書く（`app/legacy.css` 冒頭の方針どおり）。移し終えた画面が専有していた legacy のクラスは削る。
- `!important` は使わない。
- 1画面ずつ PR を分ける。おすすめの順番: 教科書一覧 → マイページ → フッター → （最後に）商品詳細を案2にそろえる。
- 行・セクション見出し・区切り線は**共通コンポーネントを 1 セット作って使い回す**（例: `ListRow` / `SectionLabel` / `RowGroup`）。画面ごとに似て非なる行を作らない。

## 全画面共通ルール（md 未満）
案2は「囲わずに、全幅の行と細い線で並べる」形。iPhone の設定アプリと同じ考え方。

- **カード（角丸＋枠＋影のかたまり）を作らない。** グループは次の 3 つで表す。
  1. 行のまとまり（白背景・画面幅いっぱい・上下に 1px の線）
  2. その上のセクション見出し（薄い灰色の帯）
  3. まとまり同士の 24px の隙間（灰色の地が見える）
- 色
  - 地の背景: `--color-bg-light`（#f4f5f6）／ 行の背景: 白
  - 区切り線: `--color-line-light`（#e8eaec）1px
  - 文字: 主 `--color-navy` / 補足 `#5f7688` / 危険操作 `#c53030`（`#ef4444` は白背景で 4.5:1 を満たさない）
- セクション見出しの帯: 上 20px / 下 8px / 左右 16px、12px・700・`#5f7688`、字間 0.06em
- 行: 高さ 52px（アバターや画像を含む行は 64px 以上）、左右 16px
  - 左にアイコン 20px（`#3d5a6e`）→ 14px の間隔 → ラベル 15px → 右端に件数バッジ → 右端の山形（chevron、16px、`#9aabb8`）
  - **区切り線はアイコンの右から引く**（左 50px から右端まで）。グループの最終行には引かない。
  - 行全体を `<button>` か `<a>` にする（`<div onClick>` は使わない）。選択中は `aria-current="page"`。
- 余白は 4 / 8 / 12 / 16 / 24 / 32px のどれかだけ。左右は 16px。
- 文字: 本文 14〜15px、補足は最小 12px。入力欄は **16px 以上**（iOS の自動ズーム防止）。
- タップ領域: 44×44px 以上。
- 例外: ログイン系だけは案3「紺の領域＋白い面」を使う（下記）。

## 画面ごとの要点

### マイページ（`V2Mypage`）
- 最上部にプロフィールの行（白・上下 20px / 左右 16px、下に 1px の線）: アバター 56px、名前 18px/900、「学部 学年 ★評価」13px、右端に「編集 ›」（13px/700、高さ 44px）。
- 以下は地が灰色。
  - 見出し「取引」→ 行グループ: ダッシュボード / 出品中の教科書（バッジ 5）/ 送った購入希望（バッジ 1）/ 受け取った購入希望
  - 見出し「サポート」→ 行グループ: メッセージ / 運営サポート
  - 24px 空けて、単独の行グループ: ログアウト（文字とアイコンを `#c53030`、山形なし）
- アイコンは Font Awesome の既存のもので可（`fa-chart-bar` / `fa-book` / `fa-paper-plane` / `fa-inbox` / `fa-comments` / `fa-headset` / `fa-sign-out-alt`）。
- **挙動の変更（要判断）**: md 未満では `/mypage`（tab なし）をこのメニュー画面にし、各行で `?tab=...` に移動する。タブ表示中は上部に「‹ マイページ」の戻る行を出す。md 以上は今のサイドバーのまま。

### 教科書一覧（`V2Listings`）
- 紺の page-header をやめる。ヘッダー直下に検索の帯（白・上下 12px / 左右 16px・下に 1px の線）。
  - 検索欄: 高さ 44px、角丸 10px、背景 `--color-bg-light`、枠なし、虫めがねアイコン、文字 16px。検索ボタンは出さず Enter で検索（`type="search"`）。
  - 絞り込み: 状態・価格・並び順を高さ 44px の丸ボタン（白・1px 枠 `#d0d5d9`・文字 14px）で横並び。はみ出す分は横スクロール。
- その下に灰色の細い帯: 「教科書一覧 **129** 件」13px。
- 一覧は**2列グリッドをやめて 1 列の行**にする。
  - 行: 上下 12px / 左右 16px、下に 1px の線。左に画像 72×96px（角丸 6px）、右にタイトル 15px/700（2行まで）、「科目・出品者」12px、下段に価格 18px/900＋状態バッジ（12px）。
  - 行全体が `<a>`。

### 商品詳細（`V2Detail`）
- 画像は左右余白なし・角丸なしで全幅（高さ 240px）。
- その下に白のタイトル帯（16px）: タイトル 20px/900、「科目・状態」13px、下に 1px の線。
- 以下は地が灰色。
  - 見出し「商品情報」→ 行グループ: 状態 / 受け渡し場所 / 出品日 / 出版年 / ISBN。各行は高さ 48px 以上、**左にラベル（14px・`#5f7688`）、右に値（14px/700・紺）**。値が長い行は右寄せのまま折り返す。
  - **価格の行は商品情報から外す**（下部バーと重複するため）。
  - 見出し「出品者」→ 行 1 つ: アバター 40px（紺地に白文字）、名前 15px/700、右に「★5」、山形。
  - コメントがある場合は 見出し「出品者のコメント」→ 白の段落（14px / 行間 1.8、上下 16px）。
- **下部固定バー**: 左に価格（22px/900）＋「税込・送料ゼロ」12px、右に主ボタン（高さ 52px、角丸 10px）。上端に 1px の線。
  - `BottomTabBar` と重ならないよう `bottom: var(--bottom-nav-h)` に置く。本文の下端にはバーの高さ分の余白を足す。
  - ボタン文言は現状の「準備中です」を維持してよい（モックの「購入希望を送る」は仮）。
- 「気になる」「シェア」は下部バーの外（本文の下）。

### ログイン系（`V3Login`）※ここだけ案3「紺ヘッダー一体型」
- 上部: 紺（`--color-navy`）の領域。上 72px / 下 64px。中央に大きいロゴ「TETOMI」（Raleway 40px/900、字間 0.14em）とキャッチ 13px（白 75%）。
  - サイト共通の `Navbar`（紺）とこの紺の領域は、**境目の線や隙間なしでつなげる**。
  - `Navbar` のロゴと大きいロゴが重複して見える場合は、`Navbar` 側を残してこちらはキャッチだけにする案もあり（実機で見て判断）。
- 下部: 白い 1 枚の面を紺の領域に 24px 重ね、上の角だけ 20px の角丸。内側 上 24px / 左右 16px / 下 32px。中にさらに枠や背景つきのかたまりを置かない。
- 見出し「ログイン」22px/900、説明 14px。フォームまで 24px。
- 入力欄: 高さ 52px、角丸 10px、背景 `--color-bg-light`、枠なし、文字 16px。ラベル 13px/700。入力欄同士 16px。
- 「30日間保持」のチェック（20px、行の高さ 44px）と「パスワードをお忘れですか？」を 1 行に左右で並べる（13px）。
- ログインボタン: 高さ 52px、全幅、角丸 10px。
- 画面下端（`mt-auto`）に「はじめての方は **新規登録**・デモで試す」（14px、各リンク 44px）。
- **`.auth-note` の開発メモ（autocomplete / セッション側の責務…）は利用者向けではないので削除。**
- 新規登録・パスワード再設定も同じ作り。新規登録は項目が多いので白い面の中は縦スクロールでよい。

### フッター・ページ送り（`V2Footer`）
- ページ送り: 44px の丸ボタン、現在ページは紺塗り、次ページは山形のアイコンボタン。
- フッターは紺のまま。上下の余白は 12px / 24px。
  - 「SERVICE」「INFO」は 12px・700・字間 0.12em・白 60%。
  - リンクは高さ 48px の行、14px・白 90%、右端に山形（白 50%）、行間の線は `rgba(255,255,255,0.12)`。
  - 法定ページのリンクは 13px・高さ 44px で横並び、最後にコピーライト 12px。

## 確認
- 幅 360 / 390 / 767 / 768 で表示し、767 以下だけが変わっていること。
- 角丸＋枠＋影のカードが残っていないこと（例外: 画像の角丸、入力欄、バッジ、ボタン）。
- 区切り線の左端がアイコンの右にそろっていること。グループの最終行に線が残っていないこと。
- iPhone 実機で入力欄をタップしてもズームしないこと。
- 商品詳細で、下部バーと `BottomTabBar` が重ならず、本文の最後がバーに隠れないこと。

方針の記録: `docs/decisions/mobile-ui-no-boxes.md`
見た目の正解: このフォルダの `V1*.dc.html`（幅 390px。ブラウザで開くと一部崩れるが、中身は普通の HTML/CSS として読める）

| ファイル | 画面 | 主な対象コード |
|---|---|---|
| `V1Mypage.dc.html` | マイページ | `app/mypage/page.tsx` |
| `V1Listings.dc.html` | 教科書一覧 | `app/listings/page.tsx`, `components/ListingCard.tsx` |

## 適用範囲
- **md（768px）未満だけ**に適用する。境目は既存の `BottomTabBar`（`md:hidden`）と同じ。
- md 以上（タブレット・PC）は今のカードのレイアウトのまま。変えない。
- `docs/mockups/mypage-responsive/` の案A（スマホ版 `Main.dc.html`）は、md 未満については本ハンドオフで置き換え。タブレット版（`TabletA.dc.html`）は有効。

## 実装のしかた
- Tailwind で書く（`app/legacy.css` 冒頭の方針どおり）。移し終えた画面が専有していた legacy のクラスは削る。
- `!important` は使わない。
- 1画面ずつ PR を分ける。おすすめの順番: ログイン系 → 商品詳細 → 教科書一覧 → マイページ → フッター。

## 全画面共通ルール（md 未満）
- **箱を作らない**: 背景は白 1 枚。`border` / `box-shadow` / 背景色つきの角丸コンテナでグループを囲まない。
  - 例外: 入力欄（背景 `--color-bg-light`、枠なし）、画像の角丸、状態バッジ、ボタン。
- グループは**余白と見出し**で区切る。
  - 画面の左右余白: 16px（`px-4`）
  - セクション同士: 32px（`gap-8`）
  - セクション見出し: 17px / weight 900 / `--color-navy`、見出しと中身の間 12px
  - 同じグループ内の要素: 8〜16px
  - 余白は 4 / 8 / 12 / 16 / 24 / 32 / 48px のどれかだけを使う
- 区切り線は原則使わない（例外: フッター上端と、商品詳細の下部バー上端の 1px のみ）。
- 文字: 本文 14〜15px、補足は最小 12px（10〜11px は使わない）。入力欄は **16px 以上**（iOS の自動ズーム防止）。
- タップ領域: 44×44px 以上（見た目が小さくても余白で広げる）。
- 色: ログアウトなどの危険操作は `#c53030`（白背景で 4.5:1 を満たす。`#ef4444` は不足）。

## 画面ごとの要点

### ログイン（`V1Login`）
- カード（`.auth-card`）をやめ、白い画面に直接置く。上 40px / 左右 16px。
- 見出し「ログイン」28px/900、説明 14px。見出しブロックとフォームの間 32px。
- 入力欄: 高さ 52px、角丸 10px、背景 `--color-bg-light`、枠なし、文字 16px。ラベル 13px/700。
- ログインボタン: 高さ 52px、全幅、角丸 26px。
- 「パスワードをお忘れですか？」「デモユーザー（佐藤 花子）で試す」は中央寄せの文字リンク（高さ 44px）。
- 「新規登録」は画面下端に寄せる（`mt-auto`）。
- **`.auth-note` の開発メモ（autocomplete / セッション側の責務…）は利用者向けではないので削除。**
- 新規登録・パスワード再設定も同じルールで揃える。

### 商品詳細（`V1Detail`）
- 画像は左右余白なし・角丸なしで全幅（高さ 280px）。
- タイトル周り: 状態バッジ（出品中・書き込み少し）→ タイトル 22px/900 → 科目 13px。
- 「商品情報」見出し＋2列の項目（ラベル 12px 灰、値 15px/700）。枠・背景なし。ISBN は 2 列ぶち抜き。
- **価格の行は商品情報から外す**（下部バーと重複するため）。
- 「出品者のコメント」見出し＋本文。
- **下部固定バー**: 左に価格（22px）＋「税込・送料ゼロ」、右に主ボタン（高さ 52px）。上端に 1px の線。
  - `BottomTabBar` と重ならないよう `bottom: var(--bottom-nav-h)` に置く。本文の下端にはバーの高さ分の余白を足す。
  - ボタン文言は現状の「準備中です」を維持してよい（デザイン上の「購入希望を送る」は仮）。
- 「気になる」「シェア」「出品者」は下部バーの外（本文の下）。

### 教科書一覧（`V1Listings`）
- 紺の page-header をやめ、白地に見出し「教科書一覧」24px/900＋説明 13px。
- 検索欄: 高さ 48px、角丸 24px（丸）、背景 `--color-bg-light`、枠なし、虫めがねアイコン、文字 16px。検索ボタンは出さず Enter で検索（`type="search"`）。
- 絞り込み: 状態・価格・並び順を丸いボタン（高さ 44px、背景 `--color-bg-light`）で横並び。はみ出す分は横スクロール。
- 件数 13px。
- カード: **枠・影なし**。画像（高さ 150px、角丸 10px）の下に文字を直接置く。2 列、列間 16px・行間 24px。
  - タイトル 14px/700、科目 12px、価格 18px/900＋状態バッジ（12px）。

### マイページ（`V1Mypage`）
- プロフィール: アバター 64px ＋ 名前 20px/900 ＋「学部 学年 ★評価（件数）」13px。箱なし。
- メニューは 2 セクション: 「取引」（ダッシュボード / 出品中の教科書 / 送った購入希望 / 受け取った購入希望）、「サポート・設定」（メッセージ / 運営サポート / プロフィール編集）。
  - 各行: 高さ 56px、左に 40px の丸いアイコン（背景 `#eef2f5`）、ラベル 15px、右端に件数バッジ。区切り線なし。
- ログアウトは最後に赤の文字ボタン。
- **挙動の変更（要判断）**: md 未満では `/mypage`（tab なし）をこの「メニュー画面」にし、各行で `?tab=...` に移動する。タブ表示中は上部に「← マイページ」の戻るリンクを出す。md 以上は今のサイドバーのまま。

### フッター（`V1Footer`）
- 紺背景をやめ白地に。上端に 1px の線だけ。上 32px / 左右 16px。
- ロゴ＋キャッチ → リンク 2 列（各行 44px、14px）→ 法定ページのリンク（13px、44px）→ コピーライト 12px。
- 一覧のページ送り: 44px の丸ボタン、現在ページは紺塗り。

## 確認
- 幅 360 / 390 / 767 / 768 で表示し、767 以下だけが変わっていること。
- どの画面でも、枠線・影・色つき背景で囲まれたかたまりが（例外以外）無いこと。
- iPhone 実機で入力欄をタップしてもズームしないこと。
- 商品詳細で、下部バーと `BottomTabBar` が重ならず、本文の最後がバーに隠れないこと。

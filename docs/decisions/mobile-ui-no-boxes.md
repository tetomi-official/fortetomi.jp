# スマホでは「箱」のデザインをやめる（案1: 余白と見出し）

作成日: 2026-09-20

## 決めたこと
- 画面幅 md（768px）未満では、カード・枠線・影でグループを囲むデザインをやめる。
- グループは余白と見出しで区切る（案1「余白と見出し」を採用）。
- md 以上（タブレット・PC）は現行のカードのレイアウトを維持する。

## 理由
- 灰色の背景に白いカードを並べる作りだと、画面が部品ごとに分断されて見え、一体感がなかった。
- 枠や背景で囲まれたものは 1 つのまとまりに見える（共通領域の法則。Palmer, 1992）。囲いは、線でつなぐなど他の「外から足す」まとまりの手がかりより強く効く（Montoro ら, 2017）。囲いを多用すると、部品ごとに島のように分かれて見える。
- スマホは画面が狭く、カードの枠と内側の余白の分だけ内容の幅も削られていた（例: ログインの入力欄が幅 370px 中 248px）。

## 比較した案
| 案 | 概要 | 不採用の理由 |
|---|---|---|
| 案2 リスト型 | 全幅の行と区切り線 | 線が多く事務的。一覧の画像が小さくなる |
| 案3 紺ヘッダー一体型 | 紺の上部から白いシートがつながる | 紺の帯の分、1画面目に入る情報が減る |

## 検証のしかた
- 実装後、各画面をぼかして見て、意味の区切りより多いかたまりが見えないか確認する。
- マイページで目的の項目（例: 受け取った購入希望）に着くまでの時間を、実装前と比べる。
